# Kitroid logo files

Regenerate with `node scripts/brand.mjs` (source: `public/icons/kitroid.svg`). Green `#059669`, mint dot `#a7f3d0`.

| File | Use it for |
|---|---|
| `kitroid-icon.svg`, `kitroid-icon-{16…1024}.png` | App icon (rounded square). **Google OAuth branding logo: `kitroid-icon-120.png`** |
| `kitroid-icon-square.svg`, `-square-{120,512,1024}.png/.jpg` | Profile pictures that crop to a circle themselves (Facebook, Telegram, Google, Buy Me a Coffee) |
| `kitroid-mark-{green,white,black}.svg/-512.png` | The "K." alone on a transparent background (white = on green/dark backgrounds) |
| `kitroid-logo-light.svg/.png` | Icon + "Kitroid" for white backgrounds (documents, receipts header, slides) |
| `kitroid-logo-dark.svg/.png` | Icon + "Kitroid" for dark backgrounds |
| `kitroid-social-1200x630.png/.jpg` | Link preview / Facebook post / cover (also served as `/og-image.png`) |
| `kitroid-favicon.ico` | Browser tab icon |

The wordmark SVGs use the system font (Segoe UI / Arial); use the PNGs where the font must look exactly the same.
